# cinegrade

The color page of DaVinci Resolve, as a headless CLI, for Apple Log footage
off the Blackmagic Camera app.

Built because the grading half of Resolve is separable: a conversion, a look,
and a set of optical effects. None of that needs a 3GB NLE, and unlike Resolve
it can be driven by a script or an agent.

## What it does

| Resolve concept | Here |
| --- | --- |
| CST in / CST out around a DaVinci Wide Gamut timeline | `convert.working_space: dwg` |
| Color Space Transform node | `convert` stage, a generated 65-cube CST |
| Rec.709-A vs Rec.709 Gamma 2.4 output | `convert.encode` |
| Primaries wheels | `primaries` stage |
| Linear-gamma node for white balance | log-domain offset in the LOG stage |
| LUT key output / opacity | `look.mix` |
| Curves node (black lift, highlight roll-off) | `primaries.black_lift` / `.highlight_rolloff` |
| Soften then sharpen nodes | `detail.soften` / `.sharpen` |
| LOOK node with a creative LUT | `look` stage, any `.cube` |
| Halation / bloom / glow | `fx.halation`, `fx.bloom` |
| Radial blur, edge defocus | `fx.radial_blur` |
| RGB split | `fx.rgb_split` |
| Vignette, grain | `fx.vignette`, `grain` |
| Scopes, gallery stills | `scopes`, `stats`, `compare` |

## Color science

Apple Log is decoded with the official transfer function from Apple's white
paper (via `colour-science`, which cites Apple 2023 and AMPAS 2023), not an
eyeballed curve. Verified anchors on the default `aces` path:

| Scene | Apple Log code | Rec.709 out, rec709a | Rec.709 out, gamma24 |
| --- | --- | --- | --- |
| 18% grey card | 0.4883 | **0.3599** | **0.3919** |
| 90% white | 0.6817 | 0.7832 | 0.7993 |
| 4 stops over grey | 0.8243 | 0.9374 | 0.9424 (rolls off, does not clip) |
| 1% deep shadow | 0.2086 | 0.0443 | 0.0574 |

This table used to have one output column and did not say which encode it was.
That was not an oversight so much as a symptom: `convert.encode` could not reach
the direct path at all, which always loaded the cube `make_cst.py` bakes with its
own default of gamma24, so the shipped default of rec709a silently rendered
gamma24 and there was only ever one answer to record. Both are real now, and the
gamma24 column is the one those published numbers always were.

The Apple Log code column is also the contrast pivot for the `direct` working
space, because primaries run before the output transform and there is no CST IN
on that path. Pivoting on an output code instead, which the engine used to do,
makes contrast shift exposure.

Three things this gets right that hand-rolled Apple Log conversions usually
miss: the footage is limited range and must be expanded to full; the YUV to RGB
matrix is BT.2020, not BT.709; and Apple Log code 0.0 decodes to a **negative**
linear value, which has to be clamped before the gamut matrix or it poisons the
result.

## The look library

Twenty looks, all generated by `tools/make_looks.py`. Pick by name on the CLI
(`-l punch`) or by preset (`-p punch`). The saturation column is the measured
mean HSV saturation of the look applied to two real frames from `footage/`, a
4K golden hour exterior and a soft interior selfie, so it is a like-for-like
number rather than a description. The ungraded frames measure **0.271** and
**0.184**, which is the line to compare against.

| # | look | what it is | sat ext / int |
| --- | --- | --- | --- |
| 1 | `neutral` | identity, the CST on its own | 0.271 / 0.184 |
| 2 | `kodak2383` | print film: cool dense shadows, warm mids, creamy roll-off | 0.260 / 0.214 |
| 3 | `teal_orange` | the separation, heavier handed than blockbuster is subtle | 0.335 / 0.317 |
| 4 | `warm_film` | soft, warm, low contrast travel look | 0.283 / 0.191 |
| 5 | `bleach` | bleach bypass: silver retained, contrast up, colour down | 0.130 / 0.152 |
| 6 | `nordic` | cold, desaturated, blue-green shadows, overcast | 0.230 / 0.206 |
| 7 | `forest` | dense cool shadows, olive greens, creamy highlights | 0.218 / 0.215 |
| 8 | `golden_haze` | milky lifted blacks, golden mids, very soft contrast | 0.259 / 0.184 |
| 9 | `premium` | the house look: warm skin, olive foliage, cool shadow | 0.215 / 0.183 |
| 10 | `natural` | reference matched: warm, restrained, honest | 0.230 / 0.187 |
| 11 | `blockbuster` | loud, deliberate teal and orange, meant to be obvious | 0.445 / 0.386 |
| 12 | `blockbuster_max` | same engine pushed until the grade is the point | 0.641 / 0.493 |
| 13 | `reels` | calibrated to the reference reels: restraint plus range | 0.243 / 0.295 |
| 14 | `film_portrait` | colour negative: flatter than the source, warm, skin first | 0.253 / 0.179 |
| 15 | `film_tungsten` | tungsten stock shot in daylight: blue-cyan, magenta reds | 0.229 / 0.215 |
| 16 | `commercial` | flat, clean, brand-safe, leaves headroom for titles | 0.228 / 0.160 |
| 17 | `blue_hour` | cold night: ambient goes blue, bulbs stay warm | 0.260 / 0.275 |
| 18 | `interior` | warm interior under practical light, rich rather than hazy | 0.350 / 0.229 |
| 19 | `punch` | high contrast, high saturation, every hue left where it was | 0.454 / 0.322 |
| 20 | `silverblue` | near monochrome with a steel blue cast | 0.065 / 0.072 |

Looks 14 to 20 were built against stated numeric targets (tonal spread, black
floor, hue family shares, saturation window) and verified on both frames plus a
fixed set of probe colours; the targets and the traps they cost are in each
look's docstring in `tools/make_looks.py`. Every one of them has a matching
preset of the same name.

Those numbers are measured at `look.mix` 1.0, which is what the presets ship
with. That is the exception to the usual advice to sit at 0.6 to 0.8: these
looks were calibrated at full strength, so full strength is the setting the
measurements describe, and dialling `mix` down moves every column back toward
the ungraded row in proportion.

Reading the spread: `commercial` is the flattest (tonal spread 13% narrower
than the source), `punch` and `blockbuster` are the two loud ones and differ in
kind rather than degree (`punch` moves no probe hue more than 2.3 degrees,
`blockbuster` collapses the palette onto two targets), and `silverblue` is the
only look under 0.10 saturation.

## Layout

```
content/
  cinegrade                 wrapper, use this
  footage/                  source clips (gitignored)
  refs/                     look references (gitignored)
  grade/
    cinegrade.py            engine
    AGENTS.md               operating guide, read this first
    presets/*.json          flat, clean, natural, cinekit, forest,
                            golden_haze, premium, cinematic, reels,
                            blockbuster, blockbuster_max, and one per
                            calibrated look: film_portrait, film_tungsten,
                            commercial, blue_hour, interior, punch, silverblue
    luts/technical/         generated CSTs (gitignored)
    luts/looks/             looks + the drop-in slot for purchased LUTs
    tools/                  colorlib.py, make_cst.py, make_looks.py
    out/, stills/           renders (gitignored)
```

## Provenance

Every LUT here is generated from scratch by `tools/`. Nothing is derived from
a commercial pack. The node tree follows standard grading practice (convert,
balance, look, optical effects), which is the same structure any professional
grade uses. Purchased LUTs drop into the `look` slot and are not redistributed.
